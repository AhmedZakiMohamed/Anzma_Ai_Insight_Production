# CEO Product References

This folder preserves exact project-local copies of the three DOCX blueprints and four concept images supplied for the Anzma AI Insight direction on 25 November 2026. The files are kept unchanged. Their copied SHA-256 hashes matched the corresponding files in `E:\Downloads` at the time of preservation.

## How to use these references

- `Anzma_AI_Insight_Self_Service_Blueprint_4_Visuals (Promise).docx` captures the customer promise, self-service onboarding, connector and KPI discovery, multi-surface experience, release gates and four illustrative visual concepts.
- `Anzma_AI_Insight_Self_Service_Integration_Blueprint (Promise).docx` is a separate supplied blueprint with the same core integration and self-service direction. Keep it as its own source; do not treat it as a duplicate file merely because major sections overlap.
- `Anzma_AI_Insight_v0_2_Engineering_Architecture.docx` gives a proposed near-term engineering release, technical boundaries, work split, and acceptance evidence. It is a plan, not proof that its target features are built.
- The four WhatsApp JPEGs are visual concepts. Their brand names and deployment claims are not fully consistent with one another or with the written install-once/browser-access promise. The whole-solution architecture records this conflict rather than silently treating every visual as an approved product claim.

The references are product goals and design inputs. Repository code and reproducible runtime evidence establish current implementation status. Where supplied sources disagree, record the discrepancy and seek a product/CEO decision when it changes the customer promise or architecture.
