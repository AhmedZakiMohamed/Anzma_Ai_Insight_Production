# G1 Handover — 26 November 2026

## Status

The **synthetic reference engineering path is implemented and runtime-verified in this checkout**. The CEO G1 product gate is **not accepted or complete**. Evidence is from disposable environments against an uncommitted working tree; it is not an immutable-commit result or independent QA.

## What is present

- A vendor-neutral connector SDK/manifest and an independent synthetic REST reference API/connector. The reference manifest declares only `history.events`; it does not establish compatibility with any BMS, access-control, VMS, meter, or IoT vendor.
- Core ingestion through contract 1.0, stable event IDs, source-scoped external-asset mappings, bounded retries, cursor checks, and explicit upstream completeness handling.
- A local SQLite connector checkpoint/outbox. It saves the exact Core payload before submission, advances only after full Core acceptance, replays an unchanged batch after a lost response, and skips an already completed range. It is local runner state, not a Core checkpoint service or multi-host coordinator.
- Two typed, evidence-backed analyses (`doors.after_hours` and `devices.offline_frequency`) and chat routing that returns the same evidence. Completeness remains `UNKNOWN`; an empty result does not prove the source had no records.
- A first guided-connection preview: authenticated `/setup` page and `POST /api/v1/connectors/test-connection`. It tests the reference connector only, through an operator-approved exact origin. HTTP needs a second explicit allowlist. The route rejects redirects, caps its request body at 8 KiB, masks the submitted bearer credential, does not persist it, and returns sanitized connection status, latency, and declared capabilities.
